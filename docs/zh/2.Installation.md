# 2. 安装

本部分介绍如何安装 DeepH-pack 及相关软件包。

- `DeepH-dock`：一组通用工具的集合，包括结构搜索/生成、数据接口与后处理工具。
- `DeepH-pack`：主程序，包含神经网络模块、图构建器，以及训练/推理功能。

**注意：**

- 本教程使用的是重构后的 DeepH-pack 版本（即将发布），速度与功能都有大幅提升。
- 本教程不包含*第一性原理*计算程序的安装。我们默认读者能够自行完成这类计算。


## 2.1. 安装 UV：一个用 Rust 写的 Python 环境管理器

首先配置 `uv` 环境，这是一个快速且多功能的 Python 包管理器。安装方式见
[uv 官网](https://docs.astral.sh/uv/#installation)。

在 Linux 或 macOS 上，一条命令即可安装（需要联网）：
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

强烈建议根据自己的网络位置配置高性能镜像。例如中国大陆的用户可以使用
[TUNA](https://mirrors.tuna.tsinghua.edu.cn/help/pypi/) 提供的镜像：
```bash
# 将以下内容加入 ~/.config/uv/uv.toml
[[index]]
url = "https://mirrors.tuna.tsinghua.edu.cn/pypi/web/simple/"
default = true
```


## 2.2. 用 UV 创建 deeph 的 Python 虚拟环境

用 `uv` 创建一个 `python 3.13` 环境：

``` bash
mkdir ~/.uvenv
cd ~/.uvenv
uv venv deeph --python=3.13 # 会在当前目录下创建名为 deeph 的虚拟环境
```

**注意：** 实际使用中，DFT 计算通常在 CPU 集群上进行，而神经网络的训练/推理在 GPU 集群上完成。
因此请根据自身情况选择环境的存放位置。

创建完成后，可以用下面的命令激活 uv 虚拟环境：
```bash
source ~/.uvenv/deeph/bin/activate
```
方便之处在于，装进 `deeph` 环境的所有文件都位于 `~/.uvenv/deeph` 目录下。要迁移 Python 环境，
只需打包并搬运这个目录即可，可移植性极好。

此外，为习惯 `conda` 工作流的用户，我们也设计了直观的交互式命令来管理 uv 环境，见下方：

```bash
# 将以下内容加入 ~/.bashrc 或你所用 shell 的 rc 文件。
uv-act() {
  local uv_source_path
  if [ $# -eq 0 ]; then
    # 列出所有 uv 环境
    local envs=($(/bin/ls -1 ${HOME}/.uvenv))

    if [ ${#envs[@]} -eq 0 ]; then
      echo "No available environments found in ~/.uvenv"
      return 1
    fi

    # 打印环境列表
    echo -e "\033[0;36mAvailable environments:\033[0m"
    echo -e "\033[0;36m------------------------------------\033[0m"
    for i in "${!envs[@]}"; do
      printf "\033[1;33m%2d) %s\033[0m\n" "$((i+1))" "${envs[$i]}"
    done
    echo -e "\033[0;36m------------------------------------\033[0m"

    # 读取用户选择
    local choice
    printf "\033[0;36mSelect environment (1-${#envs[@]}):\033[0m"
    read -p " " choice

    # 校验选择
    if [[ ! "$choice" =~ ^[0-9]+$ ]] ||
       [ "$choice" -lt 1 ] ||
       [ "$choice" -gt "${#envs[@]}" ]; then
      echo "Invalid selection" >&2
      return 1
    fi

    # 激活环境
    uv_source_path="${HOME}/.uvenv/${envs[$((choice-1))]}/bin/activate"
  else
    uv_source_path="${HOME}/.uvenv/$1/bin/activate"
  fi
  echo source ${uv_source_path}
  source ${uv_source_path}
}

uv-new() {
    # 校验参数
    if [ $# -ne 2 ]; then
        echo "Error: Requires 2 arguments: <environment_name> <python_version>" >&2
        return 1
    fi

    local env_name="$1"
    local python_version="$2"
    local env_dir="${HOME}/.uvenv/${env_name}"

    # 检查环境是否已存在
    if [ -d "$env_dir" ]; then
        echo "Error: Environment '$env_name' already exists" >&2
        return 1
    fi

    # 创建环境
    uv venv "$env_dir" --python="${python_version}" || {
        echo "Error: Failed to create environment" >&2
        return 1
    }
}
```

把上述内容加入 `~/.bashrc` 并 source 之后，就可以直接创建新的 `deeph` uv 虚拟环境：
```bash
uv-new deeph 3.13 # 名称，Python 版本
```

再用下面的命令激活 `deeph` 环境：
```bash
uv-act # <- 直接回车
> Available environments:
> ------------------------------------
>  1) deeph
> ------------------------------------
> Select environment (1-1): 1 # <- 输入 '1' 后回车
```


## 2.3. 安装 DeepH-dock

请确认已按上一节所述激活了 uv 环境，并且当前处于你创建的 `deeph` 环境中。

例如，运行下面的命令来确认环境：
```bash
which python
```
输出应当是该环境 Python 解释器的路径，例如：
`~/.uvenv/deeph/bin/python`

执行下面这一条命令，即可自动安装 `DeepH-dock` 及其全部依赖：
``` bash
uv pip install ./deepx_dock-1.0.0-py3-none-any.whl
```

**注意：**

- `deepx_dock-1.0.0-py3-none-any.whl` 是预先提供好的 wheel 包。
- DeepH-dock 在 CPU 与 GPU 设备上都能运行。
- 安装过程需要联网。


## 2.4. 安装 DeepH-pack

请确认已按上一节所述激活了 uv 环境，并且当前处于你创建的 `deeph` 环境中。

``` bash
uv pip install ./deepx-1.0.6+light-py3-none-any.whl[gpu] --extra-index-url https://download.pytorch.org/whl/cpu
```

这会安装全部依赖，包括 GPU 版本的 jax、flax 等。对于只有 CPU 的平台，把 `[gpu]` 换成 `[cpu]` 即可。

**注意：**

- `./deepx-1.0.6+light-py3-none-any.whl` 是预先提供好的 wheel 包。
- `--extra-index-url` 指定了 pytorch 的下载地址。之所以以 "cpu" 结尾，是因为 pytorch 只在 CPU 一侧被使用。
- 请注意不要将本教程中的 `DeepH-pack` 与其他开源的 DeepH 软件包混淆。本教程提供的所有包都以 `deepx`
  命名，它是 `deeph-jax` 的简写，目的是在未来的正式发布中，避免用户把这个*全新*的、基于 JAX 的公开版本
  与此前开发的实验性程序（例如 `DeepH-E3`，其包名为 `deeph`）混淆。
