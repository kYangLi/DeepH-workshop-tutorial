# DeepH Workshop Tutorial

Hands-on tutorials for the **DeepH-pack** workshop: environment setup, dataset generation,
model training, inference, and the universal materials model.

Each year's workshop has its own self-contained edition. The editions are written and
updated independently, so the material for a given year always matches what was taught
there.

## Editions

- **[Workshop 2025](2025/index.md)** — installation, data interface, training, inference,
  and the universal materials model.
- **[Workshop 2026](2026/index.md)** — under construction.

## About DeepH

DeepH is a deep-learning framework for modelling DFT electronic Hamiltonians, developed by
Prof. Yong Xu and Prof. Wenhui Duan's group at the Department of Physics, Tsinghua
University. Instead of fitting potential energy surfaces, it learns the electronic
Hamiltonian — the quantity from which band structures, density of states and other
mean-field-level properties follow.
